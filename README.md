# 🛒 Retail Sales Analysis

## 📌 Project Overview

This project analyzes a retail sales database using SQL to answer real-world business questions.

The analysis focuses on customer behavior, sales performance, product performance, returns, and business KPIs.

---

## 🗂 Dataset

The project uses a SQLite database built from the following tables:

- Customers
- Orders
- Order Details
- Products
- Categories

The original CSV files and SQLite database are available inside the **Datasets** folder.

---

## 📊 Business Questions

Examples of business questions answered in this project:

- Which customers generate the highest revenue?
- Which cities experienced declining sales?
- Which products improved or declined?
- Which products have the highest return rate?
- Which customers became inactive?
- What are the top-selling products?
- How do sales compare between May and June?
